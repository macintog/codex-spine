# Provenance

This repo-owned skill adapts selected investigative and epistemic patterns from
the `why` and `how` skills in Cursor's `pstack` plugin at immutable commit
`60c641e4fad674784b30abcf9f8915dea39df38d`:

- project: `https://github.com/cursor/plugins`
- pinned project: `https://github.com/cursor/plugins/tree/60c641e4fad674784b30abcf9f8915dea39df38d/pstack`
- pinned source: `https://github.com/cursor/plugins/tree/60c641e4fad674784b30abcf9f8915dea39df38d/pstack/skills`
- license at reviewed commit: `https://github.com/cursor/plugins/blob/60c641e4fad674784b30abcf9f8915dea39df38d/pstack/LICENSE`
- upstream files: `pstack/skills/why/SKILL.md` and
  `pstack/skills/how/SKILL.md`
- intake decision: `adapt-pattern-only`

The adaptation preserves evidence-before-narrative, confidence calibration,
explicit gaps, competing hypotheses, and the rule that code shape does not by
itself prove intent. It deliberately removes the upstream mandatory all-source
sweep, MCP enumeration, fixed model assignments, and subagent orchestration.
